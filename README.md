# sankofanvst.app

Site statique du domaine `sankofanvst.app` (B-49), publié par GitHub Pages
depuis un dépôt public dédié (Pages n'est gratuit que sur un dépôt public ;
`sankofa-nvst` est privé). Source versionnée ici ; la publication est une
copie de ce dossier.

- `index.html` : page d'accueil.
- `404.html` : sert les liens d'invitation `https://sankofanvst.app/join/<code>`
  (code lu dans l'adresse, affiché comme texte, jamais interprété).
- `CNAME` : domaine personnalisé.

Le bouton « Ouvrir dans Sankofa » vise `sankofa://join?code=…` ; l'app ne
déclare pas encore ce schéma (B-70, refonte D-035).
